## 📋 Descripción del Proyecto

**Nexo OS** es una distribución de Linux derivada de Parrot Security (base Debian) con el entorno de escritorio LXQt, diseñada específicamente para entusiastas de la tecnología, profesionales de la ciberseguridad y usuarios que buscan un rendimiento ágil con una identidad visual única (protagonizada por nuestro icónico Tux hacker con trompeta y gamepad).

Este repositorio (`mydmedia/Nexo-OS-V1.0.1`) contiene los registros, configuraciones y la estructura base de la versión **1.0.1**.

---

## ⚡ Características Principales (v1.0.1)

* **Arsenal de Ciberseguridad:** Integración completa de la suite de herramientas de auditoría, análisis forense y pentesting (`parrot-tools-full`).
* **Entorno Ligero y Rápido:** Escritorio LXQt optimizado para un consumo mínimo de recursos y máxima velocidad.
* **Identidad Visual Propia:** Pantallas de bienvenida, menús de arranque GRUB/Syslinux y fondos de pantalla personalizados de Nexo OS.
* **Soporte de Persistencia:** Configurado de fábrica para permitir almacenamiento persistente al ejecutarse desde unidades USB Live.
